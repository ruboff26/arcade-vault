## Next.js version caveat

Next.js 16.4 / React 19.3 — APIs differ from older training data. Before writing Next.js code, read the relevant guide in `node_modules/next/dist/docs/` (`01-app`, `02-pages`, `03-architecture`, `04-community`). `AGENTS.md` is auto-regenerated by `next dev`; leave it be.

## Architecture notes

- App Router only (`app/`); `@/*` path alias maps to the repo root.
- `next.config.ts` enables `cacheComponents`, `partialPrefetching`, and `experimental.agentFeedback`. `cacheComponents` changes caching/rendering semantics (dynamic data access must be handled per the Next 16 docs), so check the docs before adding data fetching.
- Tailwind v4 is wired through Turbopack: `next.config.ts` has a `turbopack.rules` entry running `@tailwindcss/turbopack` on `*.css`. Styles are `@import "tailwindcss"` in `app/globals.css`, with theme tokens (`--background`, `--foreground`, light/dark via `prefers-color-scheme`) exposed through `@theme inline`. No `tailwind.config` / PostCSS config.
- `app/layout.tsx` uses the globally typed `LayoutProps<"/">` helper (no import) and loads Geist fonts via `next/font/google` as CSS variables.
- Language: project docs are in Spanish; the user prefers Spanish replies.
